# Project skills

Claude Code loads these automatically for sessions in this repository.

Eight skills copied unchanged from [affaan-m/ECC](https://github.com/affaan-m/ECC) (commit `d2ef268`, MIT, see `ECC-LICENSE`).
Only the skills that fit this site (Next.js + React, accessibility, SEO, design) were taken. None of ECC's hooks,
agents or commands are installed, so nothing runs automatically.

| Skill | Use it for |
|---|---|
| `frontend-a11y` | Forms, ARIA, keyboard and focus patterns in React components |
| `accessibility` | WCAG 2.2 checks: contrast, target size, focus appearance |
| `react-patterns` | Component, state and Server/Client Component structure |
| `react-performance` | Waterfalls, bundle size, re-render fixes |
| `nextjs-turbopack` | Next.js 16 dev/build behaviour |
| `seo` | Titles, descriptions, canonicals, sitemap, structured data |
| `frontend-design-direction` | Design direction, content states and the rendered finish gate |
| `design-system` | Token and visual consistency audits |

To update, copy the skill folders again from a reviewed ECC checkout.
