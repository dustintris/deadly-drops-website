# Deadly Drops Pickleball - website showcase

The same club website at three budget levels, using the club's real content
(deadlydropspickleball.com) with the pink event branding:

- `/basic.html` - $: clean single-column static page
- `/standard.html` - $$: full custom design, sticky nav, scroll animations
- `/premium.html` - $$$: Standard plus a live three.js 3D hero (spinning
  pickleball, gold orbit ring, particle field, mouse and scroll reactive)
- `/` - tier chooser landing page

## Develop

```
npm install
npm run dev
```

## Deploy

Pushing to `main` builds and deploys to GitHub Pages via
`.github/workflows/pages.yml`.
